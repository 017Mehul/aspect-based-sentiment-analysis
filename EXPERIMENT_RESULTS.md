## 1. Amazon Fine Food Reviews — review-level sentiment

**Run:** [Reproduce real-dataset experiments](https://github.com/017Mehul/aspect-based-sentiment-analysis/actions/runs/38401654200)  
**Artifact:** [Download reproduced-absa-experiments](https://github.com/017Mehul/aspect-based-sentiment-analysis/actions/runs/38401654200/artifacts/11815476331)  
**Experiment commit:** `5dd0dde72fd805f9d7fc4f0ddc986f2ddbf06b4b`

The workflow downloaded the actual `Reviews.csv` file (the Amazon Fine Food Reviews corpus) and ran the repository's six baseline configurations on a reproducible 5,000-review sample. It filtered out neutral 3-star reviews, mapping scores 1–2 to negative and 4–5 to positive. The sampled data contained **4,220 positive** and **780 negative** reviews. Evaluation used a stratified 80/20 split (1,000 held-out reviews), random seed 42.

| Model | Features | Accuracy | Macro-F1 | Weighted-F1 |
|---|---|---:|---:|---:|
| SVM (Linear) | TF-IDF | 0.908 | 0.8289 | 0.9089 |
| Naive Bayes | BoW | 0.900 | 0.8121 | 0.9005 |
| Logistic Regression | BoW | 0.898 | 0.8063 | 0.8980 |
| Logistic Regression | TF-IDF | 0.875 | 0.7860 | 0.8809 |
| SVM (Linear) | BoW | 0.888 | 0.7792 | 0.8858 |
| Naive Bayes | TF-IDF | 0.850 | 0.4962 | 0.7867 |

**Best by macro-F1:** Linear SVM + TF-IDF (0.8289 macro-F1; 0.908 accuracy).  
**Important imbalance finding:** Naive Bayes + TF-IDF achieved only **0.0385 negative recall** (negative F1 0.0741), so its 0.850 accuracy is misleading if viewed alone.

**Scope:** this is a 5,000-row sample from the real dataset, not a model trained on all 568,454 rows. These metrics are review-level sentiment metrics and do not measure aspect extraction or aspect-level polarity.

## 2. SemEval-2014 Task 4 Restaurants — supervised ABSA

**Run:** [Supervised SemEval ABSA](https://github.com/017Mehul/aspect-based-sentiment-analysis/actions/runs/38401654285)  
**Artifact:** [Download semeval14-absa-results](https://github.com/017Mehul/aspect-based-sentiment-analysis/actions/runs/38401654285/artifacts/11815127188)  
**Experiment commit:** `618f27df7cad35a663b39422446408948add641b`

The workflow trained a token-level BIO aspect-term extractor and a TF-IDF/Linear SVM aspect-polarity classifier on annotated XML. It evaluated on 800 gold test sentences containing 1,134 aspect terms.

| Task / metric | Result |
|---|---:|
| Aspect-term extraction — exact-span precision | 0.7071 |
| Aspect-term extraction — exact-span recall | 0.7302 |
| Aspect-term extraction — exact-span F1 | **0.7184** |
| Aspect polarity, given gold aspect spans — accuracy | 0.7557 |
| Aspect polarity, given gold aspect spans — macro-F1 | **0.5375** |
| End-to-end exact-span + correct polarity — precision | 0.5517 |
| End-to-end exact-span + correct polarity — recall | 0.5697 |
| End-to-end exact-span + correct polarity — F1 | **0.5605** |

Aspect polarity per-class F1:

| Polarity | F1 | Test support |
|---|---:|---:|
| Conflict | 0.2105 | 14 |
| Negative | 0.6123 | 196 |
| Neutral | 0.4679 | 196 |
| Positive | 0.8590 | 728 |

The low conflict support (14 instances) makes that class estimate especially uncertain. Macro-F1 is more informative than accuracy alone for this imbalanced four-class task.

**Evaluation distinction:** the conditional polarity score uses gold aspect spans, consistent with the polarity-classification protocol. The end-to-end score requires the model to find the exact span and predict its polarity correctly.

**Dataset provenance:** the workflow fetches `Restaurants_Train_v2.xml` from the public mirror at [davidsbatista/Aspect-Based-Sentiment-Analysis](https://github.com/davidsbatista/Aspect-Based-Sentiment-Analysis) and gold `Restaurants_Test_Gold.xml` from [HSLCY/ABSA-BERT-pair](https://github.com/HSLCY/ABSA-BERT-pair). The raw XML is not committed. Confirm the official SemEval corpus terms for your intended use and cite Pontiki et al. (2014).

## Interpretation and limitations

- The two experiments answer different questions and must not be combined into a single “ABSA accuracy.”
- The review-level Amazon result is a classical baseline on a 5,000-row sample; full-corpus training has not been run.
- The supervised ABSA model is a reproducible classical baseline, not a state-of-the-art contextual model. It has meaningful headroom, particularly for neutral/conflict polarity and end-to-end joint F1.
- Artifacts contain the generated metrics, reports, model files, and provenance metadata; the raw datasets are excluded.
